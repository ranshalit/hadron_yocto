# Hadron L4T R36.5.0 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Hadron NGX012 to L4T R36.5.0 / JetPack 6.2.2 and align its host NVIDIA runtime package set with Lumen, using matching CTI board assets.

**Architecture:** Pin only Hadron's `meta-tegra` checkout to Lumen's exact R36.5 revision and add the five NVIDIA runtime packages from Lumen's image recipe. Replace the old CTI R36.4.4 board files only with official CTI R36.5 assets specifically matching Hadron NGX012 / p3767-0003; then build and verify artifacts before updating version documentation.

**Tech Stack:** kas, Yocto Scarthgap / BitBake, meta-tegra, CTI L4T BSP, DTB/DTBO and BCT assets.

## Global Constraints

- Target L4T R36.5.0 / JetPack 6.2.2.
- Pin `meta-tegra` to `d2613418be82dd95733824a0839c185ec0e02f2d`.
- Add `tegra-libraries-core`, `tegra-libraries-eglcore`, `tegra-libraries-glescore`, `libglvnd`, and `tegra-nvsciipc`.
- Use official CTI R36.5 assets for Hadron NGX012 / p3767-0003; do not infer compatibility from the existing 36.4.4 files.
- Preserve Hadron-specific configuration and all other layer references.
- Do not use Lumen-specific board assets or flash the board during this work.
- If matching CTI assets cannot be obtained and verified, stop; do not ship a partial upgrade.
